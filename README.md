# Merik Engineering Handbook RAG Assistant

An AI-powered Retrieval-Augmented Generation (RAG) assistant designed to index the Merik Engineering Handbook and answer user queries with verifiable, chunk-level citations.

---

## Technical Overview

* **Structural Markdown Chunking:** Documents are split based on structural Markdown headers rather than arbitrary character boundaries to preserve complete semantic context.
* **Metadata Attachment:** Every chunk persists its source document identifier (`merik_fd866974_0`) and section title.
* **Hybrid Retrieval:** Blends BM25 keyword matching with dense vector similarity search for precise document recall across exact terms and semantic concepts.
* **Citation Verification:** Guarantees that every claim generated by the LLM is anchored by valid contextual chunk IDs.
* **Guardrail Refusals:** Automatically refuses queries when retrieved context relevance falls below the required threshold or when the handbook does not contain the answer.
